# 产品设计

记录 CSV Custom Pro 的定位、核心交互与产品决策。  
**改用户可见行为时，必须更新本文功能说明或决策表。**

## 定位

面向 VS Code / Cursor / Windsurf 的 **大 CSV 表格编辑器**：在编辑器里稳定打开、浏览、过滤、编辑几十 MB 级 CSV；键盘优先、低遮挡、可测。

## 核心体验

| 能力 | 说明 |
| --- | --- |
| 表格编辑 | 打开 `.csv/.tsv/.tab/.psv` 自动进 Custom Editor |
| 大文件 | 首屏有限行；宽表按单元格上限缩行数；后续 remote chunk / 窗口虚拟滚动 |
| 列过滤 | 多列 AND；可搜索列选择；chip 可编辑；与全局搜索 AND |
| 全局搜索 | 任意列子串筛行（Enter）；`×` 只清全局；与 Ctrl+F（定位不高亮筛行）区分 |
| 排序 | 表头按钮三态：升序 → 降序 → 原始 |
| 行高 | 紧凑 / 自然折行；可拖行底边，尺寸持久化 |
| 查找替换 | Ctrl/Cmd+F / H；全文件匹配 + chunk 感知定位 |
| 全文预览 | 多行/长文本用可复制浮层（非原生 title）；右键/空格可打开 |

## 过滤面板（右下角）

```text
过滤: [状态] [全局搜索] [×] [列 combobox] [包含|等于] [词] [忽略大小写] [忽略空格] [添加] [清空] [chips] | 行高
```

- 列 combobox：点开展示**全部列**（可滚）；输入列名/列号再筛。
- chip：点文字回填编辑；`×` 删单条；`清空` 删全部列条件。
- 选中表格单元格时，列选择器自动切到该列。
